# 白い教室のステージ（feat/hy/ui）

ユーザー指定で床を24×48から36×64、その後42×80へ拡大。周囲に高さ6.4の白い壁、窓枠、ホワイトボードを配置。外壁は内向きに描画し、カメラが外側に出ても室内が見える方式です。プレイヤーの座標は境界内に制限し、壁を越えて移動できません。

白い布をかけた円形テーブルは半径2.5、高さ1.6。左右4台ずつ、計8台配置し、中央と列の間に通路を設けています。通常ゲーム・検証モード・サーバーで同じ円形の衝突／登頂処理を使います。布に自分の色を塗り、Shift＋テーブル方向の移動で天板へ登れます。登頂後も継続入力で進み、天板に歩行跡を残します。途中でShiftを離すか、天板の端から出ると下へ戻ります。

布・天板・外壁に塗りが残ります。通常弾が布／外壁に当たると、その奥の床には同じ塗りを確定しません。布の色の塗り替えは登頂可否にも反映します。壁と布の塗りはルーム内のメモリに最大4096操作ずつ保持し、途中参加のスナップショットで復元します。壁面の面積は勝敗の床面積には加算しません。外壁への潜航・登頂は実装せず、ステージ外への移動を禁止します。従来の4つの箱は追加検証用として初期状態を非表示にしています。

撮影用のURLは `?dev&capture=2` または `?dev&capture=4`。撮影画面だけに固定の配色を作り、UIを隠して斜め上から描画します。実際のルームや通常モードには適用されません。

型チェック・ビルド・静的検査、関連148テストで検証。ブラウザで布の着色・高さ1.6への登頂・天板の足跡・外壁の着色・境界での停止を確認しています。全体の分類テストには既存のプロダクト語ルールと期待値の不一致が残っています。
