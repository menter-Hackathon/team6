# 発声時のインク演出：実験状況

## 現在の状態

**発声とインク演出を組み合わせた実マイクでの実験は未実施です。** 現在はユーザー指定により入力を一旦ボタンに切り替えています。

画面下中央の「押している間 インク発射」を長押しすると連続発射し、離すと止まります。マウス・タッチと、ボタンにフォーカスした状態での Space / Enter に対応します。マイクの許可・モデルの準備・分類結果は不要です。

発話検出と音量の取得処理はありますが、現在の描画処理はボタン入力のみを使用します。音声による動作が完成・実証済みという状態ではありません。

## 塗りへの影響

水滴、液体の尾、着地のしぶきは本人の画面だけの一時的な演出です。着地後に消え、床の永続描画、塗装セル、潜航判定、面積、スコアは変更しません。サーバーへ塗りの要求も送りません。分類モデルは未接続のままです。

## 確認済み

- ブラウザで長押しによる連射、解放後の停止、しぶきの消去。
- 自動テストで発射頻度とメッシュ数の上限、一時メッシュの消去。
- 型チェックと本番ビルド。
- 検証パネルの見出しをクリックして折りたたみ・再展開できること。

## これから実験すること

- マイクからの発声と演出を接続したときの反応速度と爽快感。
- 声量による大きさ・飛距離・連射頻度の調整。
- 環境音や通話相手の声への誤反応、マイク停止時の確実な停止。
- 移動・ジャンプ・潜航中の発射位置と端末ごとの描画負荷。
- 別途用意される分類結果による本当の塗りとの組み合わせ。
