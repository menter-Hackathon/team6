# Web Speech API の外部処理・規約の確認

確認日: 2026-11-18。日本語認識を比較する実験用の選択肢として追加。判定ライブラリと塗りへの接続は実験中。ユーザーからWeb Speechの認識精度がよいとの報告あり。実マイクでの定量比較は未実施。

## 確認できたこと

- Web Speech API はブラウザの認識機能を呼ぶ仕組みで、処理先が共通の一つのサービスに決まるわけではない。Chromeのネットワーク認識実装はマイク音声をGoogleの認識サービスへ送り、文字を受け取る。端末内だけで完結するという前提では使わない。
- Chrome追加利用規約も確認した。Chrome本体はGoogle利用規約と追加規約の対象で、今回確認した追加規約にはWeb Speech音声に固有の保持期間の記載はなかった。
- GoogleのChromeプライバシー通知ページは、従来の通知が廃止され、Googleプライバシーポリシーで取り扱うと案内している。
- Google利用規約はサービス利用による同意、合法で権利を持つコンテンツの送信、適用される追加規約の遵守を定める。著作権はユーザー側に残るが、対象コンテンツにはサービスの運営・改善などのための使用許可がある。
- Googleの一般プライバシーポリシーはサービス利用時の音声等を収集対象に含める。ただし、この一般説明からWeb Speech APIの音声が必ず保存・学習利用されるとも、されないとも断定できない。

## 確認できないこと・保証しないこと

調べた公式資料から、ChromeのWeb Speech API経由の音声に固有の保存期間、即時削除、モデル学習の有無、保存地域を明確に確定できなかった。JavaScriptのこのAPIには、送信先の保持期間や学習利用を指定・照会・削除要求する機能もない。「Google側も保存しない」「学習されない」とは案内しない。Google Assistantの音声履歴設定や有料のGoogle Cloud Speech-to-Textの契約・保持条件を、この機能に流用しない。

SafariなどGoogle以外の認識サービスの条件は今回未確認。ブラウザを変える際はその提供元の条件の確認が別途必要。対応インターフェースが存在しても内蔵ブラウザ等で認識サービスに接続できるとは限らない。利用料金・可用性・精度の保証やSLAもこの実装では提供しない。有料APIや課金設定、秘密鍵は追加していない。

## アプリ側の取り扱い

- 初期選択はWeb Speech API、マイクはOFF。画面に外部処理の説明と規約リンクを表示し、「外部処理でマイクをON」のクリックで初めて開始する。ページ表示・認識方法の切り替えだけでは開始しない。
- `lang=ja-JP`、途中結果を表示。ブラウザ既定のマイクを使う。Web Speech APIでは独自の音量しきい値・Whisperの音声分割処理を通さない。
- アプリで音声ファイルを作成・保存しない。認識した文章は各方式につき最新10件まで画面のメモリに保持し、履歴消去またはページ破棄で消える。今回の判定接続により、途中・確定した文章、任意の元の話、相槌判定用のユーザーネームはゲームのNodeサーバーへ送信し、結果に応じて塗る。低遅延化のため途中文字も送り、既知の短い相槌は途中認識から1個ずつ発射する。確定後の二重発射は防ぐが、途中認識が変わっても発射済みの塗りは残る。通常の文章は確定後に判定する。音声はそのNode APIへ送信しない。文章はログ・DB・ファイルに保存しないが、ライブラリ内部の一時メモリ・キャッシュは使う。詳しくは `reaction-classification.md` を参照。確定文字の `local-transcript` イベントは同じページ内だけへ通知する。ブラウザ認識の時間情報は取得できないため、推測値を表示しない。
- OFFはすでに聞いた言葉の確定を最大2秒待つ。閉じる・ページを離れる・方式の切り替えでは中断する。ユーザーがONを維持している間にサービスが自然終了した場合のみ再開し、素早い終了の繰り返しは3回で打ち切る。権限・通信エラーでは自動再試行しない。方式を自動切り替えして外部送信することもない。
- 端末内のWhisperも比較用に残す。Whisperではモデル取得後、音声を外部送信しない。
