# PCで文字起こしを試す

画面上部の「マイク・文字起こし」からパネルを開閉できます。最初は開いた状態で、マイクはOFFです。文字起こしと判定・塗りをつないだ実験用です。途中・確定した文章はゲームのNodeサーバーへ送り、指定ライブラリで判定します。

## Web Speech API（今回追加）

1. 「認識方法」で「Web Speech API · ブラウザ認識」を選ぶ（初期選択）。
2. 外部処理の説明・規約リンクを確認する。
3. 「外部処理でマイクをON」を押し、ブラウザでマイクを許可する。
4. 日本語を話すと「認識中 · 途中結果」に文字が順次表示され、確定した文章が「文字起こし結果」に入る。
5. OFFで入力を停止して最後の認識を待つ。パネルを閉じる・ページを離れる場合は中断する。

モデルのダウンロードやAPIキー設定は不要。Chromeのネットワーク認識では音声がGoogleへ送られます。外部側での保存期間・学習利用については保証できません。[確認した規約・プライバシーの内容](./web-speech-privacy.md)を参照してください。ほかのブラウザの認識サービスの条件は未確認です。

PC版ChromeでlocalhostまたはHTTPSを使ってください。内蔵ブラウザ等ではインターフェースがあってもサービスを利用できない場合があります。非対応や通信・権限の失敗を画面に表示します。入力はブラウザ既定のマイクです。入力の変更はブラウザのサイト設定で行います。音量の数値はこのAPIから取得できないため、Web Speechモードには音量バーを出しません。

## Whisper（端末内の比較用）

1. 「認識方法」で「Whisper · 端末内認識」を選ぶ。
2. 「認識モデルを準備」を押す。初回はモデルをダウンロードする。
3. 必要に応じて入力マイクを選び、「マイクをONにする」を押す。

標準のWhisper baseと、認識設定内の速度優先Whisper tinyを比較できます。モデルの準備・認識・入力中は方式を切り替えられません。モデル取得後の音声処理は端末内で行い、音声を外部へ送りません。PC内の再生音を直接取り込む機能ではありません。

小さい声・短い反応への対策として、RMSしきい値0.003、開始60ms、最短有声100ms、開始前500ms、終了無音650ms、最大10秒に設定。途中候補は発話1秒後から1.2秒間隔を目安に最新の1件へ置き換えます。推論は同時に1件までで確定を優先します。DC成分除去、最大4倍の入力補正とマイクの自動ゲイン要求も行います。ノイズを拾いやすくなる可能性があり、精度改善を実証したものではありません。

## 音声・結果の扱いと検証状況

アプリ側に録音ファイルの作成・保存・ダウンロード機能はありません。Whisperでは一時メモリの短い音声を使い、Worker入力は処理後にゼロクリアします。Web Speech APIの音声取得・送信はブラウザ側が行います。外部側の保存の有無とは区別してください。

認識結果は方式ごとに最新10件だけ画面のメモリに表示し、履歴消去・ページ破棄で消えます。途中の文章は後で変わる場合があります。確定結果だけがページ内の `local-transcript` イベントになります。途中・確定した文章と任意の元の話・ユーザーネームをNodeの判定APIへ送信します。既知の短い相槌は最初の1個の途中認識から塗り、確定後の二重発射を防ぎます。途中認識が後で変わっても発射済みの塗りは残ります。通常の文章は確定後です。分類は文章ごとの文字起こしカードと「判定 → 塗り」の履歴に表示します。詳細は [判定接続](./reaction-classification.md) を参照してください。

自動テストで日本語の途中更新・確定の重複防止・停止・権限失敗・再開の打ち切りを検証します。実マイクによるWeb SpeechとWhisperの精度・遅延の比較は未実施です。同じマイク・同じ短文で両方式を比較してください。
