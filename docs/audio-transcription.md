# 音声の文字起こし：実験状況

## 現在の状態

Transformers.js 3.8.1 と Whisper tiny / base q8 をブラウザ内の専用 Worker / WASM で動かす試験実装です。マイク入力はブラウザで選択された内蔵・外付けマイクから取得します。音声ファイルでも試せます。音声を外部へ送信せず、APIキーやAPI利用料金は不要です。初回は公開モデルのダウンロードが必要です。

分類処理と陣地の塗りには接続していません。確定した文字列は `local-transcript` イベントで別の処理に渡せます。

## 確認済み

- 型チェック、自動テスト、本番ビルド。
- ブラウザでモデルを読み込み、日本語の音声ファイルを文字にする一連の動作。
- 一例では3.4秒の音声を約2.8秒で認識。この1件は性能や精度の評価結果ではありません。

## 実験未実施

**実際のマイクで録音し、発話から文字表示までを確認する実験はまだ行っていません。**

今後、内蔵・外付けマイクの許可／停止、短いリアクションの認識精度、連続発話時の待ち時間、環境音や通話音の混入、端末・ブラウザごとの性能を確認する必要があります。発表者のターン中に録音を止めるゲームとの連携も未実装です。

## 速度優先モード

初期設定は軽量な Whisper tiny です。従来の base は「精度優先」として残しています。モデルの切り替えは待機中のみ可能で、新しいWorkerで準備し直すため、古いモデルの処理や待機音声を引き継ぎません。発話終了の無音待ちは600msから350msに短縮しています。短い間で文章が分かれる場合があります。実マイクでの認識精度・速度の評価はまだです。

### 同じ音声での簡易比較（2026-11-18）

同じブラウザで3.4秒の日本語音声ファイルを1回ずつ認識しました。モデルの準備時間・ファイル読込時間・録音終了待ちは含まない、Worker内の推論時間です。

| モード          | 認識時間 | 表示された文字列        |
| --------------- | -------- | ----------------------- |
| 速度優先 / tiny | 約1.6秒  | ぜひおはようございます  |
| 精度優先 / base | 約3.1秒  | 先生 おはようございます |

この例ではtinyが約半分の時間で処理した一方、「先生」を「ぜひ」と取り違えました。短い音声1件の簡易確認であり、平均速度や日本語の精度を保証するものではありません。実マイクの評価は未実施です。
